# Distro matrix

| Distro | Preferred install | Notes |
| --- | --- | --- |
| Linux Mint 21 / 22 | `.deb` or Flatpak | first-class target |
| Ubuntu 22.04 / 24.04 | `.deb` or Flatpak | same packages as Mint |
| Debian 12 / 13 | `.deb` or Flatpak | |
| Pop!_OS, Zorin, elementary | installer `auto` | Debian family |
| Fedora | `dnf install ayugram-desktop` | RPM Fusion |
| Arch, Manjaro, EndeavourOS | AUR `ayugram-desktop` | |
| NixOS | nixpkgs `ayugram-desktop` | |
| Gentoo / Void / ALT | see official AyuGram README | |
| Anything else | Flatpak or AppImage | |

Official Windows/macOS builds stay on https://github.com/AyuGram/AyuGramDesktop/releases
